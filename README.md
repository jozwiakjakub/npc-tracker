# NPC Tracker

Aplikacja webowa stworzona w PHP, HTML, CSS i JavaScript, umożliwiająca graczom współdzielenie informacji o lokalizacji NPC w grze online. Projekt został opracowany jako narzędzie „od graczy dla graczy” – niezależne od serwera gry.

## Funkcjonalności

- Interaktywne przekazywanie informacji o lokalizacji NPC między użytkownikami w czasie rzeczywistym.  
- System logowania z indywidualnymi kontami użytkowników (ręczna autoryzacja).  
- Weryfikacja tożsamości gracza poprzez pobieranie i sprawdzanie unikalnego ID z pliku JSON udostępnionego przez serwer gry.  
- Automatyczne wylogowanie po 35 minutach nieaktywności, aby zapobiec współdzieleniu kont.  
- Dynamiczne odświeżanie danych co kilka sekund z wykorzystaniem JavaScript.  

## Technologie

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Dane:** JSON  
- **Hosting:** własny (projekt przeniesiony na GitHub w celach prezentacyjnych)

## Cel projektu

Celem aplikacji było stworzenie lekkiego i użytecznego narzędzia dla graczy, pozwalającego na błyskawiczne informowanie innych o aktualnej lokalizacji NPC. Projekt stanowi demonstrację umiejętności programistycznych z zakresu komunikacji między użytkownikami, walidacji danych i podstaw bezpieczeństwa w aplikacjach webowych.
